我们常常会遇到一些题目, 本质是让我们用 $\varepsilon-N$ 方法求函数在趋于正无穷的极限 (因此我们本文只讨论趋于正无穷, 目前没见过趋于其他值的, 如果确实遇到了, 例如趋于实数 $x_0$, 那就将所有 $x$  替换成 $\dfrac1{x-x_0}$, 就变成趋于正无穷的情况了), 例如下面这道题: 
>设函数 $f\left( x \right)=\dfrac{x^2}{\mathrm e^x}$, 若方程 $f\left( x \right)=a$ 有 $2$ 个不等的正实根, 求 $a$ 的取值范围. 

首先讨论 $f\left( x \right)$ 的单调性, 绘制函数图像的草图: 
```desmos-graph

```
由图, 很明显答案应该是 $a\in\left( 0,\dfrac{4}{\mathrm e^{2}} \right)$, 但如果要证明,需要使用 $2$ 次零点存在定理:
1. $f\left( 0 \right)-a=-a<0<\dfrac{4}{\mathrm e^{2}}-a=f\left( 2 \right)-a$, 结合单调性证明在 $\left( 0,2 \right)$ 上有一根; 
2. $f\left( N \right)-a<0<\dfrac{4}{\mathrm e^{2}}-a=f\left( 2 \right)-a$, 结合单调性证明在 $\left( 2,N \right)$ 上有一根. 

我们现在要证明的命题等价于
>已知函数 $f\left( x \right)=\dfrac{x^2}{\mathrm e^x}$, 求证: 对于任意实数 $a\in\left( 0,\dfrac{4}{\mathrm e^{2}} \right)$, 存在实数 $N>2$, 使得 $a>f\left( N \right)$. 

那么熟悉极限的同学就能发现, 这个命题本质上就是在用 $\varepsilon-N$ 方法求极限. 不过为了防止同学们看了之后出去闲聊时因为小问题丢脸, 这里另外补充一下, 事实上,  $\varepsilon-N$ 方法要证明的是
>已知函数 $f\left( x \right)=\dfrac{x^2}{\mathrm e^x}$, 求证: 对于任意实数 $a\in\left( 0,\dfrac{4}{\mathrm e^{2}} \right)$, 存在实数 $N>2$, 使得 $\forall x>N,~a>\left| f\left( x \right) \right|$. 

根据单调性容易说明这两个命题是等价的, 但前者表述显然简单一些. 

对于这题, 有同学可能会直接写 $\lim\limits_{x\to+\infty}f\left( x \right)=0$, 这在数学上确实是成立的, 但高中由于没有学过极限的求法, 所以这样的步骤是要被扣分的. 设 $N=g\left( a \right)$,  现在我们必须找到一个符合条件的 $g$, 但问题来了, 如何找到 $g$ 呢? 实际上要找到一个刚刚好的 $g$ 是非常困难的, 我们需要放缩. 于是我们找到:
根据[[(1) 泰勒展开 & 麦克劳林公式 & 拉格朗日余项定理#高阶导]]中提到的方法证明 $\mathrm e^x>\dfrac{x^3}6~\left( x\ge0 \right)$, 于是取 $N=\dfrac6a$, 则
$$f\left( N \right)=\dfrac{N^2}{\mathrm e^N}<\dfrac{N^2}{\left( \dfrac{N^3}6 \right)}=\dfrac6N=a.$$

那这个是怎么找到的呢? 本文将会给出解决此类问题较为机械和通用的方法. 

前置知识: [[(1) 泰勒展开 & 麦克劳林公式 & 拉格朗日余项定理]].

其实从刚刚的例子就能大概看出来, 本质就是因为原不等式非常难解, 于是利用泰勒展开进行放缩, 将原本复杂的式子放缩成形如 $\dfrac c{x^k}$ 的式子, 然后就能非常轻松地比较大小了. 

## 形如 $\dfrac{P\left( x \right)}{Q\left( x \right)}$, 其中 $P\left( x \right)$ 和 $Q\left( x \right)$ 都是多项式函数. 
设 $\displaystyle P\left( x \right)=\sum_{i=0}^np_ix^i$ 和 $\displaystyle Q\left( x \right)=\sum_{i=0}^mq_ix^i$, 先假设 $p_n$ 和 $q_m$ 都是正实数, 因为负数的情况倒转结果和过程的不等式号即可; 同时假设 $m>n$, 相反的情况取倒数即可, $m=n$ 就分离常数后得到 $m>n$ 的情况. 在 $x$ 足够大的时候 (首先得是正实数), 我们可以有这么两个放缩: 
令 $\displaystyle S=\sum_{i=0}^{m-1}\left| q_i \right|$, 取
$$\displaystyle x>\dfrac2{q_m}\sum_{i=0}^{m-1}\left| q_i \right|=\dfrac{2S}{q_m},\tag1$$
故 $S<\dfrac{q_mx}2$, 那么
$$Q\left( x \right)=\sum_{i=0}^mq_ix^i\ge\sum_{i=0}^m\left( q_mx^m-Sx^i \right)\ge q_mx^m-Sx^{m-1}=x^{m-1}\left( q_mx-S \right)\overset{\left( 1 \right)}>\dfrac{q_m}2x^m.$$
另外
$$P\left( x \right)=\sum_{i=0}^np_ix^i\le\sum_{i=0}^n\left| p_i \right|x^i\le\left( \sum_{i=0}^n\left| p_i \right| \right)x^n.$$
于是
$$\dfrac{P\left( x \right)}{Q\left( x \right)}=\dfrac{\displaystyle\sum_{i=0}^np_ix^i}{\displaystyle\sum_{i=0}^mq_ix^i}<\dfrac{\left( \sum_{i=0}^n\left| p_i \right| \right)x^n}{\dfrac{q_m}2x^m}=\dfrac{\dfrac2{q_m}\left( \sum_{i=0}^n\left| p_i \right| \right)}{x^{m-n}}.$$
分子是可以计算出来的常数, 分母是幂函数, 于是就很容易控制函数的大小了. 
例如:
>已知函数 $f\left( x \right)=\dfrac{x^2+2x+3}{x^3+4x^2-x+5}$, 求证: 对于任何正实数 $a$, 均存在实数 $N$, 使得 $\forall x>N,~f\left( x \right)<a$. 

	在草稿纸上, 按照刚刚的方式得到 $f\left( x \right)=\dfrac{x^2+2x+3}{x^3+4x^2-x+5}<\dfrac{\dfrac21\left( 1+2+3 \right)}{x}=\dfrac{12}x$, 于是取 $N=\dfrac{12}a$. 
	在答题卡就先证明$f\left( x \right)<\dfrac{12}x,~\forall x>0$, 分母求导证明当 $x>0$ 时分母恒正, 交叉相乘展开得到 $x^3+2x^2+3x<12x^3+48x^2−12x+60.$, 移项得到 
	$$11x^3+46x^2−15x+60=11x^3+46\left( x-\dfrac{15}{92} \right)^2+\dfrac{10815}{184}>0,$$
	原不等式成立. 故
	$$f\left( x \right)<\dfrac{12}x<\dfrac{12}N=a.$$
	在这里, 除了了解分式函数的放缩方式, 我们还需要了解多项式如何向上或者向下放缩成"常数乘以幂函数"的形式, 因为后面还会遇到. 

## 形如 $\dfrac{P\left( x \right)}{\mathrm e^x}$, 其中 $P\left( x \right)$ 是多项式函数. 
首先通过刚刚所说的方法将其放缩为$\dfrac{P\left( x \right)}{\mathrm e^x}<\dfrac{cx^n}{\mathrm e^x}$ 的形式, 然后就是使用泰勒展开了. 
注意, 这里不是用泰勒展开放缩成多项式函数, 而是只取其中一项, 因为我们这里不是逼近, 而且不等式非常松, 可以大胆放缩. 这里就应该放缩出次数为 $n+1$ 的项, 即
$$\dfrac{cx^n}{\mathrm e^x}<\dfrac{cx^n}{\left( \dfrac{x^{n+1}}{\left( n+1 \right)!} \right)}=\dfrac{c\left( n+1 \right)!}x. $$
这样就可以令 $N=\dfrac{c\left( n+1 \right)!}a$ 了. 例子就是开头给出的例子, 此处不再赘述了. 至于 $n$ 不是整数的情况, 那就向上取整就好了, 只要比多项式的次数高就好. 
若把 $\mathrm e^x$ 换成 $a^x$, 其中 $a$ 是给定正实数, 那么可以通过 $a^x=\mathrm e^{x\ln a}$ 变形, 然后操作是一样的, 如果看不顺眼那就可以进一步 $\dfrac{P\left( x \right)}{a^x}=\left( \dfrac{P^{\frac{1}{\ln a}}\left( x )\right)}{\mathrm e^x} \right)^{\ln a}$, $\ln a$ 就一个常数, 虽然大概率是无理数, 但整体是一样的:
>已知函数 $f\left( x \right)=\dfrac{x^2}{2^x}$, 求证: 对于任何正实数 $a$, 均存在实数 $N$, 使得 $\forall x>N,~f\left( x \right)<a$. 

	取 $N=\left( \dfrac{6^{\ln2}}a \right)^{\frac1{3\ln2-2}}$, 则 $\dfrac{x^2}{2^x}=\left( \dfrac{x^{\frac2{\ln 2}}}{\mathrm e^x} \right)^{\ln 2}<\left( \dfrac{x^{\frac2{\ln 2}}}{\left( \dfrac{x^3}{6} \right)} \right)^{\ln2}=\left( \dfrac{6}{x^{3-\frac2{\ln2}}} \right)^{\ln2}=\dfrac{6^{\ln2}}{x^{3\ln2-2}}$, 故 $f\left( x \right)<\dfrac{6^{\ln2}}{x^{3\ln2-2}}<\dfrac{6^{\ln2}}{N^{3\ln2-2}}=a$.


## 形如 $\dfrac{\ln x}{Q\left( x \right)}$, 其中 $Q\left( x \right)$ 是多项式函数. 
首先同样是通过刚刚所说的方法将其放缩为$\dfrac{\ln x}{Q\left( x \right)}<\dfrac{\ln x}{cx^m}$, 但由于 $\ln x$ 的泰勒展开有取值范围限制, 即使我们有很多方法将其推广到整个实数域, 或者变形不等式使得自变量落入取值范围, 但无一例外都太复杂了. 所以这里我们要用到一个不等式
$$\ln x\le\dfrac{x^\alpha}{\alpha\mathrm e},\quad\forall x\in\left( 0,\infty \right).$$
这个很好证明. 令 $h\left( x \right)=\dfrac{x^\alpha}{\alpha\mathrm e}-\ln x$, 则 $h'\left( x \right)=\dfrac{\alpha x^{\alpha-1}}{\alpha\mathrm e}-\dfrac1x=\dfrac1x\left( \dfrac{x^\alpha}{\mathrm e}-1 \right)$, 可知 $h'\left( \sqrt[\alpha]{\mathrm e} \right)=0$ 为其唯一零点, 讨论单调性后可知 $h\left( x \right)\ge h\left( \sqrt[\alpha]{\mathrm e} \right)=0$, 即原不等式. 
我们看到一道例题来说明怎么使用这个不等式:
>已知函数 $f\left( x \right)=\dfrac{\ln x}x$, 求证: 对于任何正实数 $a$, 均存在实数 $N$, 使得 $\forall x>N,~f\left( x \right)<a$. 

	首先证明刚刚的不等式 $\alpha=\dfrac12$ 的情况, 即 $\ln x\le\dfrac{\sqrt x}{\dfrac12\mathrm e}$, 即可得到 $\dfrac{\ln x}x\le\dfrac2{\mathrm e\sqrt x}$, 此时只需要取 $N=\dfrac4{\mathrm e^2a^2}$ 即可证明原命题. 
	对于含有 $\log_ax$ 或 $\log_xa$ 的, 就使用换底公式 $\log_ax=\dfrac{\ln x}{\ln a},~\log_xa=\dfrac{\ln a}{\ln x}$, $\ln x$ 分离出来, $a$ 进系数部分了, 但需要注意当 $0<a<1$ 时调节系数不等式方向要变.

## 形如 $\dfrac{T\left( x \right)}{Q\left( x \right)}$, 其中 $T\left( x \right)=\sin x$ 或 $\cos x$, $Q\left( x \right)$ 是多项式函数. 
这种非常好处理, 因为正弦和余弦函数上界 $1$, 所以分母放缩成 $cx^m$, 分子放缩成 $1$ 就直接解决了. 
那有同学可能疑惑, 如果正弦或余弦函数出现在分母且无法化掉呢? 如果式子含有 $\tan x$ 无法化简呢? 没有关系, 因为我们能证明这样一定极限不存在, 除非是 $\dfrac0{T\left( x \right)}$. 一个更强的命题是: 
>只要函数 $P\left( x \right)$ 不具有无限振荡性, 那么 $\dfrac{P\left( x \right)}{T\left( x \right)}$ 和  $\dfrac{\tan x}{P\left( x \right)}$  的极限不存在, 其中 $T\left( x \right)=\sin x$, $\cos x$ 或 $\tan x$. 

	以及: 
>函数 $P\left( x \right)$ 是通过多项式函数, 指数函数和对数函数经过有限次加减乘除和复合得到, 则 $P\left( x \right)$ 要么恒等于 $0$, 要么不具有无限振荡性. 

	具体如何证明, 我们暂且不论, 只要知道不会出题就行了, 因为我能想到的证明方法需要使用实指数结构与模型论, 或许也没有什么简单的方法能证明. 不过大致说一下就是因为三角函数在无穷远处的行为就是震荡, 所以放在分母无法控制. 
	
## 自变量不趋于正无穷.
其实我在开头已经简述过方法了, 但我决定还是有必要举例说说:
>已知函数 $f\left( x \right)=x\sin\dfrac1{x}$, 求证: 对于任何正实数 $a$, 均存在实数 $N$, 使得 $\forall x\in\left( 0,N \right),~f\left( x \right)<a$. 

	用 $\dfrac1x$ 替换 $x$, 那么问题就能转变成:
>已知函数 $f\left( x \right)=\dfrac1x\sin x$, 求证: 对于任何正实数 $a$, 均存在实数 $N$, 使得 $\forall x>N,~f\left( x \right)<a$. 

	这我们刚刚就说过怎么处理了, 直接 $f\left( x \right)=\dfrac1x\sin x<\left| \dfrac1x\sin x \right|<\dfrac1x$, 然后就很简单了. 

## 上述函数的加减乘除和复合的函数. 
其实也是一样的, 就是把函数尽可能放缩成形如 $\dfrac{C}{x^n}$ 的式子, 一般来说, 可以按下面的顺序放缩: 三角函数, 对数函数, 多项式函数, 指数函数. 

这样我们就基本解决所有涉及 $\varepsilon-N$ 方法求函数在趋于正无穷的极限的题目了.
