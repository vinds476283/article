极限是数学分析最基础的内容, 导数也是建立在极限之上的, 但高中数学并没有涉及极限的内容, 所以一些理解难免会有偏差. 本文会简单讲述极限的定义和求法, 以深入了解极限. 但需要知道, 极限因为没学, 所以不能在考试中直接使用, 否则很有可能会被扣分. 

极限的定义比较多, 而本身就挺好懂的: 
1. 数列定义: $\varepsilon-N$ 定义
>我们称数列 $\left\{ a_n \right\}$ 收敛于 $A$, 记作 $\lim\limits_{n\to\infty}a_n=A$, 如果满足
>$$\forall\varepsilon>0,~\exists N\in\mathbb N,~\forall n>N,~\left| a_n-A \right|<\varepsilon.$$

用自然语言描述就是: 无论我给出多小的误差 $\varepsilon$, 从某一项后, 数列的所有的项都在这误差范围内. 若这样的 $A$ 不存在, 即 $\forall M>0,~\exists N,~\forall n>N,~a_n>M$, 则这个数列发散. 

2. 函数定义: $\varepsilon-\delta$ 定义
>我们称 $x\to x_0$ 时, $f\left( x \right)$ 趋于 $A$, 记作 $\lim\limits_{x\to x_0}f\left( x \right)=A$, 如果满足
>$$\forall\varepsilon>0,~\exists\delta>0,~0<\left| x-x_0 \right|<\delta\Rightarrow\left| f\left( x \right)-A \right|<\varepsilon.$$

除此之外, 极限还有各种各样的定义, 还有单侧极限, 此处不再多说. 

总而言之, **极限**是一种"虽**不能至**,然心向往之"的实践**过程**.

那我们看到一个极限之后, 如何求呢? 

在继续看方法之前, 有必要先讲讲几个名词:
- **无穷小量**: 在某个极限的过程中, 如果变量 $f\left( x\right)$ 的极限是 $0$, 那么我们称其在这个极限过程中是无穷小量; 
- **无穷大量**: 在某个极限的过程中, 如果变量 $f\left( x\right)$ 可以无限增大, 那么我们称其在这个极限过程中是无穷大量; 
需要特别注意, 无穷小量和无穷大量不是一个值, 而且还有分高阶低阶, 不能直接带入运算. 
- **未定式**: 自变量的趋向值直接代入一个表达式, 得到某种无法直接判断极限结果的形式, 这种形式就叫未定式, 常见的有如下 $7$ 种: $\dfrac00,~\dfrac{\infty}{\infty},~0\cdot\infty,~\infty-\infty,~0^0,~1^\infty,~\infty^0$, 这些形式切忌直接化简, 需要进一步计算判断; 
- **高阶无穷小**/**高阶无穷大**: 若变量 $f\left( x \right)$ 和 $g\left( x \right)$ 在 $x\to x_0$ 的过程中都是无穷小量/无穷大量, 且 $\lim\limits_{x\to x_0}\dfrac{f\left( x \right)}{g\left( x \right)}=\infty$, 那么 $f\left( x \right)$ 是 $g\left( x \right)$ 的高阶无穷小/高阶无穷大;
- **同阶无穷小**/**同阶无穷大**: 若变量 $f\left( x \right)$ 和 $g\left( x \right)$ 在 $x\to x_0$ 的过程中都是无穷小量/无穷大量, 且 $\lim\limits_{x\to x_0}\dfrac{f\left( x \right)}{g\left( x \right)}=c$, $c$ 是一个常数, 那么 $f\left( x \right)$ 是 $g\left( x \right)$ 的同阶无穷小/同阶无穷大. 特别地, 当 $c=1$ 时,  $f\left( x \right)$ 是 $g\left( x \right)$ 的**等价无穷小**/**等价无穷大**; 
- **低阶无穷小**/**低阶无穷大**: 若变量 $f\left( x \right)$ 和 $g\left( x \right)$ 在 $x\to x_0$ 的过程中都是无穷小量/无穷大量, 且 $\lim\limits_{x\to x_0}\dfrac{f\left( x \right)}{g\left( x \right)}=0$, 那么 $f\left( x \right)$ 是 $g\left( x \right)$ 的低阶无穷小/低阶无穷大. 

1. 代入法
>求 $\lim\limits_{x\to1}x+1$. 

	此处将 $x$ 直接带入 $x+1$ 是有定义的, 所以可以直接代入得到 $\lim\limits_{x\to1}x+1=1+1=2$.
	但若这样就没有极限的意义了, 所以大部分极限都是在一点没有定义的, 于是只能使用其他方法.

2. 定义法
>求证: $\lim\limits_{x\to0}x\sin\dfrac1x=0$.

	观察 $\varepsilon-\delta$ 定义, 可见取 $\delta=\varepsilon$, 则 $\left| x\sin\dfrac1x \right|=\left| x \right|\left| \sin\dfrac1x \right|\le\left| x \right|1<\delta=\varepsilon$, 即证明. 

3. 等价无穷小代换
如果一个函数是整个函数的一个因式, 那么可以直接换成等价无穷小的函数, 例如:
>求 $\lim\limits_{x\to0}\dfrac{\sin x}x$. 

	下文会提到, $\sin x\sim x$, 故$\lim\limits_{x\to0}\dfrac{\sin x}x=\lim\limits_{x\to0}\dfrac{x}x=1$. 

	>求 $\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^3}$.
	
	此时**不能**使用等价无穷小代换分别把 $\tan x$ 和 $\sin x$ 换掉, 因为它们不是整个函数的一个因式, 其正确结果是等价无穷小代换 $\tan x-\sin x\sim\dfrac{x^3}2$ 得到 $\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^3}=\lim\limits_{x\to0}\dfrac{\left( \dfrac{x^3}2 \right)}{x^3}=\dfrac12$, 如果是分别代换则会得到 $\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^3}=\dfrac{x-x}{x^3}=0$.

	我们来看一些常用的等价无穷小:
	$$\sin x\sim x,\quad\tan x\sim x,\quad 1-\cos x\sim\dfrac{x^2}2,$$
	$$\ln\left( x+1 \right)\sim x,~\mathrm e^x-1\sim x,\quad\left( 1+x \right)^\alpha-1\sim\alpha x,\quad a^x-1\sim x\ln a.$$
	 等价无穷小代换本质时泰勒展开一阶近似 (前置知识: [[(1) 泰勒展开 & 麦克劳林公式 & 拉格朗日余项定理]]), 例如: $\sin x=x-\dfrac{x^3}6+o\left( x^3 \right)$, 显然等价无穷小取了其一阶近似.

4. 抓大头
有些函数部分项的收敛速度远远慢于其他项, 于是在趋近过程中能直接舍掉. 
>求 $\lim\limits_{x\to+\infty}\dfrac{x^3+2x^2-1}{3x^3-6x+6}$.

	很容易理解, 当 $x$ 非常大的时候, $x^2,~x$ 和常数相比 $x^3$, 对函数值的贡献微乎其微, 所以可以直接舍掉, $\lim\limits_{x\to+\infty}\dfrac{x^3+2x^2-1}{3x^3-6x+6}=\lim\limits_{x\to+\infty}\dfrac{x^3}{3x^3}=\dfrac13$. 
	但舍去无穷小量不是随意舍去, 有时候一些无穷小量可能乘以了一个无穷大量, 或者有一个无穷大量次方, 让其重见天日, 变成一个常数甚至无穷大量, 这个时候就不能随意舍去了, 例如 $\lim\limits_{x\to+\infty}\left( 1+\dfrac1x \right)^x$, 如果直接将括号内的 $\dfrac1x$ 当作无穷小量舍去, 那么会得到结果时 $1$, 而正确的结果时 $\mathrm e$, 因为次方时无穷大, 将无穷小量放大了. 

5. 洛必达法则
洛必达法则定义如下: 
>若 $\lim\limits_{x\to x_0}f\left( x \right)=+\infty$, $\lim\limits_{x\to x_0}g\left( x \right)=+\infty$, 则 $\lim\limits_{x\to x_0}\dfrac{f\left( x \right)}{g\left( x \right)}=\lim\limits_{x\to x_0}\dfrac{f'\left( x \right)}{g'\left( x \right)}$. 

	>若 $\lim\limits_{x\to x_0}f\left( x \right)=0$, $\lim\limits_{x\to x_0}g\left( x \right)=0$, 则 $\lim\limits_{x\to x_0}\dfrac{f\left( x \right)}{g\left( x \right)}=\lim\limits_{x\to x_0}\dfrac{f'\left( x \right)}{g'\left( x \right)}$. 
	
	但需要特别注意, 对于其他未定式不能滥用, 需要先化成 $\dfrac00$ 或 $\dfrac\infty\infty$ 的未定式再使用洛必达: 
	1. $0\cdot\infty$: 
	$$\lim\limits_{x\to x_0}f\left( x \right)g\left( x \right)=\lim\limits_{x\to x_0}\dfrac{f\left( x \right)}{\left(\dfrac1{g\left( x \right)}\right)},$$
	或
	$$\lim\limits_{x\to x_0}f\left( x \right)g\left( x \right)=\lim\limits_{x\to x_0}\dfrac{g\left( x \right)}{\left(\dfrac1{f\left( x \right)}\right)},$$
	前者化成 $\dfrac00$, 后者 $\dfrac\infty\infty$, 根据具体题目哪种简单用哪种. 
	2. $\infty-\infty$:
	$$\lim\limits_{x\to x_0}f\left( x \right)-g\left( x \right)=\dfrac{\dfrac1{g\left( x \right)}-\dfrac1{f\left( x \right)}}{\left( \dfrac1{f\left( x \right)g\left( x \right)} \right)},$$
	化成$\dfrac00$.
	3. $0^0$:
	$$\ln\lim\limits_{x\to x_0}f\left( x \right)^{g\left( x \right)}=\lim\limits_{x\to x_0}\dfrac{g\left( x \right)}{\left( \dfrac1{\ln f\left( x \right)} \right)},$$
	化成 $\dfrac00$.
	4. $1^\infty$:
	$$\ln\lim\limits_{x\to x_0}f\left( x \right)^{g\left( x \right)}=\lim\limits_{x\to x_0}\dfrac{\ln f\left( x \right)}{\left( \dfrac1{g\left( x \right)} \right)},$$
	化成 $\dfrac00$. 经常搭配 $\ln f\sim f-1$ 使用.
	5. $\infty^0$:
	$$\ln\lim\limits_{x\to x_0}f\left( x \right)^{g\left( x \right)}=\lim\limits_{x\to x_0}\dfrac{\ln f\left( x \right)}{\left( \dfrac1{g\left( x \right)} \right)},$$
	或
	$$\ln\lim\limits_{x\to x_0}f\left( x \right)^{g\left( x \right)}=\lim\limits_{x\to x_0}\dfrac{g\left( x \right)}{\left( \dfrac1{\ln f\left( x \right)} \right)},$$
	前者化成 $\dfrac\infty\infty$, 后者化成 $\dfrac00$. 
	在使用后三者的洛必达时需要注意记得完成后还原回去原式. 

	>求 $\lim\limits_{x\to0}\dfrac{\mathrm e^x-1}{x}$. 
	
	这是 $\dfrac00$ 不定式, 可以使用洛必达 
	$$\lim\limits_{x\to0}\dfrac{\mathrm e^x-1}{x}=\lim\limits_{x\to0}\dfrac{\mathrm e^x}{1}=1.$$

	>求 $\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^3}$.
	
	这是 $\dfrac00$ 不定式, 可以使用洛必达
	$$\begin{align*}
	\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^3}
	&=\lim\limits_{x\to0}\dfrac{\sec^2x-\cos x}{3x^2}\\
	&=\lim\limits_{x\to0}\dfrac{\sec^2x\tan x+\sin x}{6x}\\
	&=\lim\limits_{x\to0}\dfrac{2\left( \sec^2x\tan^2x+\sec^4x \right)+\cos x}6\\
	&=\dfrac{2\left( \sec^20\tan^20+\sec^40 \right)+\cos x}6\\
	&=\dfrac12.
	\end{align*}$$
	注意, 每一步之后都必须检查式子是否是 $\dfrac00$ 或 $\dfrac\infty\infty$ 才使用洛必达法则, 否则不符合定义要求.
